# Data

The local analysis expects `QQQ_clean_5min.parquet` and `SPY_clean_5min.parquet` in this folder. These cleaned five-minute files are excluded from Git, so they are not available to someone who only clones the repository. The source is IEX-based market data, not consolidated volume across all US exchanges. Keep the original source files unchanged and check the data provider's licence before sharing any data.
